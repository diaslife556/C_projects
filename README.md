The developed program simulates the calculation and generation of electricity bills for service provided by HEP ELEKTRIKA. 
By selecting the "Calculate Costs" option, the program generates a bill in the form of a payment slip and outputs it to a text document. 
Users can also select the "Calculation Details" option to view the pricing associated with their tariff (the program automatically applies the "Red Model"). 
Additionally, it is possible to print a list of all devices used by the user, along with their usage hours and individual cost calculations. 
Selecting the "Exit" option in the main terminal terminates the program.
The program contains various functions/commands learned throughout the college course including: functions, pointers, structures, time, print, scan, etc.
